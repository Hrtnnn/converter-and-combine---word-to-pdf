CONVERT TOOLS - USER PACKAGE

1. Extract this ZIP to a normal folder.
2. Double-click "Convert Tools.exe".
3. Microsoft Word desktop must be installed and activated for DOC/DOCX conversion.
4. PDF combine works using the PDF files selected in the right-hand panel.

Source_Code_Locked.zip contains the developer Python source encrypted with WinZip AES-256.
It is not needed to run the application. Do not extract it for normal use.

The application does not require Python to be installed on the user's PC.
If Windows SmartScreen shows a warning, verify that this package came from the trusted developer before choosing to run it.
